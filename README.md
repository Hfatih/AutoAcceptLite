# AutoAccept Lite

Windows tray app that automatically handles selected approval buttons in the standalone Antigravity desktop app.

**[English](README.en.md) · [Türkçe](README.tr.md)**

The installer bundles Node.js and runs in the Windows notification area. Right-click the tray icon to show the terminal, pause/resume, or exit. The source is open under the MIT License; see [LICENSE](LICENSE) and [third-party notices](THIRD-PARTY-NOTICES.md).
